# ابزار آزمایش «دوکان لطیف»

اپ یک فایل است (`docs/index.html`) و منطق حسابش داخل یک IIFE بسته است.
برای آزمایش، `mkhook.js` یک نسخهٔ ابزارگذاری‌شده می‌سازد (`test-index.html`)
که توابع داخلی را روی `window.__*` باز می‌کند. آن فایل ساختنی است و در گیت
نمی‌آید.

## یک فرمان

```bash
./tools/run-all.sh          # همهٔ آزمایش‌ها + fuzz کوتاه
./tools/run-all.sh long     # fuzz دراز (seed تصادفی)
```

## دو نوع آزمایش

**۱) `verify*.js` — آزمایش‌های نشانه‌دار.** هر فایل یک بخش را می‌سنجد
(دفتر قرض، صندوق، عکس، فروش بازار، باطل‌کردن، …). این‌ها می‌گویند «آنچه
ساختیم همان کاری را می‌کند که خواسته بودیم».

**۲) `fuzz.js` — حلقهٔ قانون.** دنباله‌های تصادفی از کارهای واقعی دوکان
(فروش، خرید، باطل، شمارش، برداشت جنس، …) اجرا می‌شوند و **بعد از هر قدم**
قوانین دفتر بررسی می‌گردند. این می‌گوید «هیچ ترتیبی از کارها نمی‌تواند
دفتر را خراب کند» — همان چیزی که آزمایش نشانه‌دار پیدا کرده نمی‌تواند.

```bash
node tools/fuzz.js [تعداد‌دنباله] [قدم‌در‌هر‌دنباله] [seed]
```

هر شکست با **seed** و دنبالهٔ دقیق ذخیره می‌شود (`fuzz-fail.json`)، پس
دقیقاً تکرارشدنی است. بعد:

```bash
node tools/minimise.js     # کوچک‌ترین دنباله‌ای که باز هم می‌شکند
```

## قوانین دفتر (که fuzz می‌سنجد)

۱. **رد پول = رقم صندوق** — مانده در فهرست حرکت‌ها باید دقیقاً به رقم صندوق برسد.
۲. **صندوق گزارش = صندوق زنده**.
۳. **جمع اجزای صندوق = رقم صندوق**.
۴. **قرض هر مشتری = قرض قبلی + فروش قرضی − دریافت‌ها** (و نقد + جنس = مجموع دریافت).
۵. **قرض هر تامین‌کننده = قرض قبلی + باقی فاکتورها − پرداخت‌ها**.
۶. **فروش دوکان + فروش بازار = مجموع فروش** (و همین برای فایده).
۷. **فایده = فروش − تمام‌شد − ضایعات − کسری صندوق**، و **فایدهٔ نهایی = فایده − مصارف**.
۸. **جمع فایدهٔ هر جنس = فروش − تمام‌شد**.
۹. هیچ رقمی **NaN** نشود.
۱۰. **مصارف صندوق = مصارف کل − مصارف جنسی** (برداشت جنس نباید در صندوق بیاید).
۱۱. **رفت‌وبرگشت سنک**: بعد از `collectData → applyData` هیچ رقمی عوض نشود.

اگر ویژگی نویی اضافه شد که رقم مالی می‌سازد، **قانونش را هم اینجا اضافه
کنید** — ورنه fuzz آن ناحیه را نمی‌پاید.

## چرا این‌ها هستند

تمام تصمیم‌های مالی دوکان بر این رقم‌ها بنا است. یک لاجک غلط، یک سال
ضربهٔ مالی می‌زند. باگ‌هایی که تا حال همین حلقه‌ها گرفتند از نوعی بودند که
با خواندن کود پیدا نمی‌شدند — مثلاً «فایدهٔ ساختگی از هوا» و «رد پول که با
صندوق جور نمی‌آمد».
