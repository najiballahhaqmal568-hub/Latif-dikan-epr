# دوکان لطیف — اپ مدیریت دوکان

اپ Flutter برای مدیریت یک دوکان خورد مواد خوراکه. **بدون انترنت** با دیتابیس محلی
SQLite کار می‌کند. تمام صفحه‌ها به زبان **دری** و **راست‌به‌چپ (RTL)**؛ واحد پول **افغانی**.

نقشه کامل اپ در فایل `plan-dukan-latif.md` است. این پروژه مرحله‌به‌مرحله ساخته می‌شود.

## این مرحله چه چیز دارد (مرحله اول)

۱. **اجناس و موجودی**
- اضافه‌کردن جنس با: نام، نوع (وزنی/دانه‌ای)، واحد (کیلو/دانه)، قیمت خرید، قیمت فروش،
  تعداد موجود، تاریخ خرابی (اختیاری).
- لیست همه اجناس با تعداد موجود (اخطار رنگی وقتی موجودی صفر است).
- ویرایش و حذف جنس.

۲. **فروش تیز**
- جستجوی تیز بالای صفحه.
- دکمه‌های بزرگ اجناس.
- جنس **وزنی** → دیالوگ مقدار (نیم / ۱ / ۲ / ۵ + تایپ دلخواه).
- جنس **دانه‌ای** → یک ضربه = یک دانه (ضربه دوباره +۱).
- سبد فروش پایین صفحه با **مجموع زنده**.
- دو دکمه بزرگ: «تمام — نقد» و «تمام — قرض» (قرض با نام اختیاری مشتری).
- بعد از فروش، موجودی خودکار کم می‌شود.

۳. **فاکتور خرید از تامین‌کننده**
- ثبت فاکتور خرید: نام تامین‌کننده، تاریخ، اجناس با تعداد و قیمت خرید،
  مجموع، پرداخت‌شده، باقی‌مانده.
- موجودی خودکار **زیاد** می‌شود و قیمت خرید هر جنس تازه می‌گردد.

۴. **دفتر قرض تامین‌کننده**
- برای هر تامین‌کننده مجموع قرض باقی‌مانده.
- ثبت پرداخت که قرض را کم می‌کند.

۵. **دفتر قرض مشتری‌ها**
- فروش قرضی با نام مشتری، به قرض همان مشتری اضافه می‌شود.
- تب «قرض‌ها» با دو دفتر: **مشتری‌ها** و **تامین‌کننده‌ها**.
- ثبت دریافت/پرداخت که قرض را کم می‌کند.

۶. **ضایعات و تاریخ خرابی** (زیر تب «بیشتر»)
- اخطار اجناسی که تا ۱۴ روز دیگر تاریخ‌شان تیر می‌شود (یا تیر شده).
- ثبت ضایعات (خراب / تاریخ‌تیر) که موجودی را کم و ضرر را حساب می‌کند.

۷. **مصارف خانه** (زیر تب «بیشتر»)
- ثبت پیسه‌ای که از دوکان برای خرچ خانه کشیده می‌شود، با توضیح و مجموع.
- فایده دوکان را کم نمی‌کند؛ فقط یک دفتر جدا برای دیدن مقدار خرچ.

۸. **گزارش‌ها و فایده هر جنس** (زیر تب «بیشتر»)
- انتخاب دوره: امروز / این ماه / همه.
- فروش (نقد/قرض)، قیمت تمام‌شد، ضرر ضایعات، **فایدهٔ دوکان**، مصارف خانه (جدا)،
  قرض فعلی مشتری/تامین‌کننده، و **فایده هر جنس** (مرتب نزولی).

۹. **وای‌فای** (زیر تب «بیشتر»)
- نوع جنس «وای‌فای» با واحد جی‌بی؛ خرید/فروش فی جی‌بی، فروش مثل جنس وزنی.
- صفحهٔ وای‌فای: جی‌بی مانده، تاریخ ختم، و دو اخطار — «جی‌بی کم» (۲۰) و «نزدیک/تیر ختم».
- انتقال باقی‌ماندهٔ تاریخ‌تیرشده به ضایعات.

> بخش‌های بعدی (شمارش ماهانه، سنک آنلاین) بعداً از روی نقشه اضافه می‌شوند.

## ساختن و اجرا

پیش‌شرط: **Flutter نصب شده (نسخه 3.27 یا بالاتر)**.

این ریپو فقط کد `lib/` و `pubspec.yaml` را دارد؛ پوشه‌های پلتفرم (android/ios) را با
دستور زیر بساز:

```bash
# ۱) پوشه‌های پلتفرم را بساز (کد lib/ دست‌نخورده می‌ماند)
flutter create .

# ۲) وابستگی‌ها
flutter pub get

# ۳) بررسی کد
flutter analyze

# ۴) اجرا روی امولیتور یا تلیفون وصل
flutter run

# ۵) ساختن فایل APK برای نصب در تلیفون
flutter build apk --release
# خروجی: build/app/outputs/flutter-apk/app-release.apk
```

## ساختار کد

```
lib/
  main.dart                     # MaterialApp، RTL، locale دری، تیم
  theme/app_theme.dart          # دکمه‌های بزرگ و رنگ‌ها
  utils/formatting.dart         # قالب پول افغانی و مقدار
  db/database_helper.dart       # SQLite: جدول‌های products, sales, sale_items
  models/                       # product، cart_item، sale
  repositories/                 # product_repository، sale_repository
  screens/
    home_screen.dart            # نویگیشن: فروش / اجناس
    products/                   # لیست و فورم اجناس
    sales/                      # صفحه فروش + CartModel
  widgets/                      # quantity_dialog، product_tile_button، cart_panel
```

## دیتابیس

SQLite محلی (`dukan_latif.db`). در این مرحله سه جدول:
- `products` — اجناس و موجودی
- `sales` — فروش‌ها (نقد/قرض)
- `sale_items` — قلم‌های هر فروش

جدول‌های دیگر نقشه در مرحله‌های بعد با ارتقای نسخه دیتابیس اضافه می‌شوند.
